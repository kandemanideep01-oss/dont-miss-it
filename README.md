## ✨ Features & Architecture

### 1. 🌌 3D Cinematic Visuals & Animations
- **3D Hyperspace Warp**: Full-screen cinematic warp speed opening transition with starlight acceleration.
- **3D Rotating Earth Globe**: Real-time rotating spherical wireframe globe with glowing atmospheric ring and dynamic flight trajectories.
- **Tri-Axis Gyroscopic Gimbal**: Rotating orbital rings around the destination card with 3D diamond core.
- **3D Navbar Emblem**: Floating geometric polyhedron emblem embedded in the application header.
- **Translucent Polyhedra**: Interactive background prisms and icosahedra floating behind content.

### 2. 🤖 Google Gemini 3.5 Flash AI Travel Copilot
- Pre-linked with Google Gemini API key.
- Real-time generative reasoning for spiritual pilgrimage protocols, deity legends, darshan timings, transit estimates, and customized daily itineraries.
- Fast heuristic offline engine fallback for 100% offline availability.

### 3. ⚡ Supabase Cloud Database & Authentication
- Integrated official `@supabase/supabase-js@2` SDK.
- Pre-linked with Supabase Publishable Keys for client-side browser database operations.
- Real-time cloud sync for user authentication and saved custom itineraries.
- Dual-key switcher and project URL configuration interface in Settings.

### 4. 🎨 7 Dynamic Background Atmosphere Themes
- ☀️ **Modern Light**: Crisp high-contrast daylight theme.
- 🌌 **Midnight Obsidian**: Sleek deep dark space theme.
- ✨ **Cosmic Nebula**: Violet and indigo interstellar aura.
- 🌅 **Golden Sunset**: Warm amber and crimson twilight gradient.
- 🌿 **Sacred Emerald**: Deep mystical forest emerald atmosphere.
- 🌊 **Deep Oceanic**: Marine blue aquatic vibes.
- ⚡ **Cyberpunk Neon**: High-energy electric magenta and cyan glow.

### 5. 🛕 11 Sacred God Temples of India & World Destinations
- **Indian Sacred Temples**: Kedarnath, Kashi Vishwanath (Varanasi), Tirupati Balaji, Vaishno Devi, Somnath, Puri Jagannath, Mahakaleshwar (Ujjain), Meenakshi Amman (Madurai), Golden Temple (Amritsar), Badrinath, and Ramanathaswamy (Rameswaram).
- **International Cultural Wonders**: Tokyo (Japan), Paris (France), Dubai (UAE), New York City (USA), Rome (Italy), London (UK), Singapore, Sydney (Australia), Cairo (Egypt), and Rio de Janeiro (Brazil).
- Complete guides including darshan rituals, holy prasad & sacred dishes, historical context, dress codes, transit maps, and budget calculators.

- **Frontend**: React 18, Babel Standalone, Vanilla CSS3 Variables, HTML5 Canvas 2D/3D WebGL

- **Cloud Backend**: Supabase PostgreSQL & Auth (`@supabase/supabase-js@2`)
- **Hosting**: Netlify Edge Global CDN (`https://gofamily.netlify.app/`)
- **Version Control**: Git & GitHub (`kandemanideep01-oss/dont-miss-it`)

## 📦 How to Deploy & Run Locally

### Running Locally:
1. Clone this repository:
   ```bash
   git clone https://github.com/kandemanideep01-oss/dont-miss-it.git
   cd dont-miss-it
   ```
2. Open `index.html` directly in any web browser, or serve with Python:
   ```bash
   python -m http.server 8000
   ```
3. Open `http://localhost:8000` in your browser.
